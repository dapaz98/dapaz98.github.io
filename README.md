# Cartão acadêmico digital — Eduardo da Paz Rodrigues

Página estática minimalista para publicar com GitHub Pages e usar como destino da NFC.

## Antes de publicar
1. Abra `index.html`.
2. Encontre o comentário `TODO: substitua o href abaixo pelo link real do seu Currículo Lattes`.
3. Substitua o endereço genérico do Lattes pelo link direto do seu currículo.
4. Revise os dados e áreas de interesse.

## Publicar no GitHub Pages
1. Entre em https://github.com/new
2. Crie um repositório público chamado `dapaz98.github.io`.
3. Use **Add file → Upload files** e envie `index.html` (e opcionalmente este README).
4. Clique em **Commit changes**.
5. Abra **Settings → Pages** e confirme a publicação pela branch `main` e pasta `/(root)`, se essa opção aparecer.
6. Aguarde a publicação e teste `https://dapaz98.github.io` no iPhone.

O GitHub Pages pode levar alguns minutos para publicar. O site ficará público na internet.

## Gravar a NFC usando iPhone
1. Primeiro teste o cartão com NFC Tools → **Ler**. Não escolha opções de apagar ou bloquear.
2. Depois que o site estiver publicado e funcionando, abra NFC Tools → **Gravar** → **Adicionar registro** → **URL/URI**.
3. Informe `https://dapaz98.github.io` e confirme a gravação.
4. Aproxime a parte superior traseira do iPhone da NFC para gravar, conforme a orientação do app.
5. Leia novamente o cartão e teste em outro celular, se possível.

**Importante:** se o chip da BRACIS estiver bloqueado para escrita, não será possível trocar o endereço gravado. Nesse caso, verifique se o endereço atual da BRACIS permite editar o perfil ou redirecionar o link. Não bloqueie o chip depois de gravar; isso costuma ser irreversível.
